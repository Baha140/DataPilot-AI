# DataPilot AI

Autonomous AI Agent for Data Analysis.

## Description

DataPilot AI is an autonomous AI agent designed
to automate data analysis operations.

## Technologies

- Python 3.11
- Pandas
- DuckDB
- FastMCP
- Ollama (Qwen2.5:3b)
- Streamlit
- Plotly

## Main Features

- Data loading
- Data diagnosis
- Intelligent cleaning
- Data analysis
- SQL queries
- Automatic visualization
- Autonomous AI agent
